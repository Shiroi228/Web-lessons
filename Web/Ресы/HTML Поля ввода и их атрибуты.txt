        number - только цифры
        password - вводимые символы будут как "*"

        search - форма для поиска
        file - форма для загрузки файла
        url - форма для ссылок
        date(datetime-local) - форма для даты (с дополнением времени)
        month, week, time - месяц, неделя, время
        radio - форма для кружочка (для выбора какого-либо варианта ответа, например)
        checkbox - как "radio", только галочки. Можно ставить и убирать. Более удобная форма
        submit и reset - дублируем вариант "button"
        datalist - список с вариантами ответов (пример ниже). Можем также написать свой вариант -->
